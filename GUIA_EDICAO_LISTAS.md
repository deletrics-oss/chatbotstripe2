## 💬 EXEMPLOS PRÁTICOS

### **Exemplo 1: Adicionar Produtos (Voz/Texto Bagunçado)**

**Mensagem atual:**
```
🎁 MEGA PROMOÇÃO

- Notebook Dell - R$ 2.500,00
- Mouse Logitech - R$ 45,00
- Teclado Mecânico - R$ 350,00
```

**Você fala/digita na IA:**
```
adicione moto e por 59,99 moto g3 89 moto g5 120
```

**Resultado automático:**
```
🎁 MEGA PROMOÇÃO

- Notebook Dell - R$ 2.500,00
- Mouse Logitech - R$ 45,00
- Teclado Mecânico - R$ 350,00
- Moto E - R$ 59,99
- Moto G3 - R$ 89,00
- Moto G5 - R$ 120,00
```

✅ **A IA:**
- Entendeu o texto bagunçado
- Extraiu produtos e preços
- Manteve o formato de bullet (-)
- Adicionou ao final
- Completou preços com ,00

## 🎨 FORMATOS SUPORTADOS

A IA detecta e mantém **automaticamente** qualquer formato:

### Bullets com traço (-)
```
- Item A - R$ X
- Item B - R$ Y
```

### Bullets com ponto (•)
```
• Item A - R$ X
• Item B - R$ Y
```

### Lista numerada
```
1. Item A - R$ X
2. Item B - R$ Y
```

### Dois pontos
```
Item A: R$ X
Item B: R$ Y
```

### Sem formatação
```
Item A - R$ X
Item B - R$ Y
```

## 🚀 COMO USAR

1. **Escreva sua lista inicial** na mensagem
2. **Clique no botão IA** ✨
3. **Digite ou fale** sua instrução:
   - "adicione produto X por Y reais"
   - "inclua 3 itens: A, B, C"
   - "remova o produto X"
   - "altere o preço de X para Y"
4. **Clique em Gerar**
5. **Pronto!** A IA editou perfeitamente mantendo o formato

---

## 💡 DICAS IMPORTANTES

### ✅ **FAZER:**
- Usar modo **"Substituir mensagem atual"**
- Ter uma lista já escrita na mensagem
- Falar naturalmente, pode ser bagunçado
- Deixar a IA trabalhar

### ❌ **NÃO FAZER:**
- Usar modo "Anexar" para editar (use "Substituir")
- Tentar editar mensagem vazia
- Se preocupar com formatação na fala
